# سامانه صدور مجوز فعالیت های اقتصادی — فرانت‌اند

ورود، داشبورد، اطلاعات پایه (کشور / استان / شهر)، مدیریت کاربران و نقش‌ها، و منوی حساب / تغییر رمز / زبان.

## راه‌اندازی

```bash
cp .env.example .env
npm install
npm run dev
```

در حالت توسعه، `/api` به بک‌اند پروکسی می‌شود (`vite.config.ts`).

ورود پیش‌فرض: `admin` / `Admin1234`
